## (a) HC Dynamo Pardubice *(1923-dnes)* — **HLAVNÍ KLUB**

**Začátky:** První hokej v Pardubicích na **Matičním jezeře 1913** *(první zápas vs ČSS Praha)*. **Organizovaný hokej založen 1923 panem Vilémem Weissem** jako **LTC Pardubice** *(LTC = Lawn Tennis Club)*. Pravidelné soutěže od **1930/31**.

| Roky | Název |
|---|---|
| **1923** | **LTC Pardubice** *(zal. Vilém Weiss; LTC = Lawn Tennis Club)* |
| 1947 | Před Vánoci 1947 **otevřen ZS s umělou ledovou plochou** |
| **1949** | **Sokol Pardubice I** *(SLOUČENÍ LTC Pardubice + Rapid Pardubice)* |
| **1950** | **Slavia Pardubice** *(3 roky NEJVYŠŠÍ soutěž)* |
| **1953** | **DSO Dynamo Pardubice** |
| **1960** | **TJ Tesla Pardubice** *(Tesla = elektrotechnický podnik; nejdelší období!)* |
| **1991** | **HC Pardubice** *(po revoluci, vypuštění Tesla)* |
| **1995** | HC Pojišťovna IB Pardubice *(sponzorské)* |
| **1997** | HC IPB Pojišťovna Pardubice |
| **2002** | HC ČSOB Pojišťovna Pardubice |
| **2003** | HC Moeller Pardubice |
| **2009** | HC Eaton Pardubice |
| **2011** | HC ČSOB Pojišťovna Pardubice |
| **2015-dnes** | **HC Dynamo Pardubice** *(návrat historického názvu)* |

**Klíčový moment 1949:** Sloučení **LTC Pardubice + Rapid Pardubice** = **Sokol Pardubice I**. **1950** v divizi vyhráli + tříkolová kvalifikace = postup do nejvyšší soutěže.

**Tituly CSSR/CR:** **6 mistrovských titulů!**
- **1973** *(formace Martinec – Novák – Šťastný)*
- **1987** *(s Dominikem Haškem)*
- **1989** *(Hašek, Šejba, Janecký)*
- **2005**
- **2010**
- **2012**

**1960:** Historicky první medaile *(bronz)*. **Zastřešení ZS** v 60. letech.

**Domácí stadion:** **Enteria Aréna** *(dříve ČEZ Aréna)*. **Klubové barvy:** červená a bílá.

**Současnost:** Majitel od 2020 **Petr Dědek** *(miliardář)*. Od 1993 **nepřetržitě v ELH** *(jeden z 5 klubů)*.

## (b) Rapid Pardubice *(do 1949)*

Druhý hlavní pardubický klub vedle LTC. **1949 fúze s LTC** = Sokol Pardubice. Před tím samostatný klub *(meziválečné období)*.

## Důležité poznámky

- **LTC** = Lawn Tennis Club *(tenis na trávě, kurty se v zimě polévaly vodou pro hokej — tradiční přechod)*
- **Tesla Pardubice** = elektrotechnický podnik *(rádia, mikrofony, polovodiče), klubu se říkalo Tesla 1960-1991*
- **Tesla Mikrofony Strojírny (TMS)** = pobocka Tesly *(50. léta)*
- **Vilém Weiss** = zakladatel klubu 1923
- **LTC vs. LTC Praha** = různé kluby! Tady LTC Pardubice, jinde slavnější LTC Praha (1903-1948)
