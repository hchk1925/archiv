## (a) HC Baník Sokolov *(1945-dnes)* — **HLAVNÍ KLUB**

**Klub založen 1945** jako **SK FHD Dolní Rychnov** *(FHD = Falknovské hnědouhelné doly, hornický podnik)*.

| Roky | Název |
|---|---|
| **1945** | **SK FHD Dolní Rychnov** *(zal., FHD = Falknovské hnědouhelné doly)* |
| 1948 | Sokol FHD *(sokolizace)*, mesto se prejmenovalo z **Falknov nad Ohři** na **Sokolov** |
| 1949 | ZSJ FHD/Banik FHD |
| **1953** | **TJ Banik Sokolov** *(DSO Banik)* |
| **1961** | Umělý ZS *(první umělé ledování)* |
| **1967** | **Postup do 2. NHL** *(1 sezóna)* |

| 1971-73 | ZS zastřešen *(zastrešení dokončeno)* |

| 1990 | Znovu 1. NHL |
| 1997 | Sestup do 2. ligy |

**Domácí stadion:** ZS Sokolov *(kapacita ~3000)*. **Klubové barvy:** modrá, červená, bílá.

## (b) Mestské části / okolí Sokolovska

### **Dolní Rychnov** *(městská část Sokolova!)*
